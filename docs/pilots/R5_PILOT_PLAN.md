# R5 Pilot Plan

## Purpose

Prepare AI-Project-Factory for a controlled new-project pilot without starting development until human approval of the project brief.

## Scope

- Reuse F0-F5 and R1-R4 components.
- Register an independent project.
- Execute analysis, architecture, development, quality, security, release, deployment, and documentation workflows.
- Preserve factory and project separation.
- Use staging only.

## Entry criteria

- Factory tests pass.
- Runtime R3 operational.
- R1 and R2 validators available.
- OpenCode agents load.
- Human-approved project brief.

## Exit criteria

- Project deployed to isolated staging.
- Rollback tested.
- Quality certificate valid.
- Traceability valid.
- Documentation complete.
- Independent audit PASS.
