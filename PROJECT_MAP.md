- `README.md`: project overview.
- `AI_START_HERE.md`: universal AI entry.
- `AGENTS.md`: agent operating rules.
- `PROJECT_CONTEXT.md`: permanent context.
- `PROJECT_STATUS.md`: operational state.
- `PROJECT_DECISIONS.md`: decision log.

- `PROJECT_HANDOFF.md`: handoff protocol.

## Directories

- `.opencode/`: OpenCode executable agents, commands, skills.
- `agents/`: normative agent definitions by domain.
- `contracts/`: normative contracts.
- `orchestration/`: workflows, policies, task and state management.
- `standards/`: coding, git, security, testing, deployment.
- `quality-gates/`: Quality Gate definitions.
- `templates/`: reusable templates.
- `integrations/`: OpenCode, Git, Docker, CI/CD.
- `schemas/`: JSON Schemas.
- `tests/`: contract, policy, orchestration tests.
- `docs/`: architecture, decisions, progress, audits.
