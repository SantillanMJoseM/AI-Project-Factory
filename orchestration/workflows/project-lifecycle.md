# Project Lifecycle Workflow

## Stages

F0 Foundation -> F1 Requirements -> F2 Architecture -> F3 Development -> F4 Quality -> F5 Release -> F6 Deployment.

## Rules

- Each stage has objective, tasks, owner, deliverables, acceptance criteria, tests, evidence, status, audit.
- No stage may be marked complete without evidence.
- Critical operations require human approval.
- Independent audit before release.
