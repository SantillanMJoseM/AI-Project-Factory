# F3 Development Workflow

1. DEVELOPMENT INTAKE: Recover approved F2 package.
2. TASK DECOMPOSITION: Coordinator decomposes functionality into tasks.
3. INTERFACE CONTRACTS: Define module interfaces.
4. DATABASE IMPLEMENTATION: Implement persistence.
5. BACKEND IMPLEMENTATION: Implement services and logic.
6. FRONTEND IMPLEMENTATION: Implement interfaces.
7. INTEGRATION: Integrate components and services.
8. COMPONENT TESTING: Execute individual tests.
9. INTEGRATION TESTING: Verify communication.
10. CODE REVIEW: AG-013 reviews technical quality.
11. QUALITY AUDIT: AG-002 verifies deliverables.
12. REMEDIATION: Correct defects.
13. DELIVERY PACKAGE: Generate executable project version.
14. HUMAN APPROVAL: Present results and request approval.
