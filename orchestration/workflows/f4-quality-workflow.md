# F4 Quality Workflow

1. QUALITY INTAKE: Identify project, commit, version, architecture, technologies, requirements.
2. TEST PLANNING: AG-012 generates test plan.
3. AUTOMATED TESTING: AG-012 executes tests.
4. CODE REVIEW: AG-013 inspects code.
5. PERFORMANCE AUDIT: AG-014 evaluates performance.
6. SECURITY AUDIT: AG-015 analyzes security.
7. FINDINGS CONSOLIDATION: Coordinator consolidates without altering auditor conclusions.
8. QUALITY REVIEW: AG-002 performs independent audit.
9. REMEDIATION: Defects assigned to development agents.
10. RE-TESTING: Affected and regression tests repeated.
11. FINAL AUDIT: Gatekeeper verifies remediation.
12. QUALITY CERTIFICATION: Generate Quality Certificate.
13. HUMAN APPROVAL: Present result to user.
