# Coordination Workflow

1. User submits requirement.
2. AG-001 analyzes and classifies.
3. AG-003 evaluates risk.
4. AG-001 creates tasks and dependencies.
5. AG-001 delegates to subagents.
6. Subagents execute and return evidence.
7. AG-001 collects deliverables.
8. AG-002 audits independently.
9. If FAIL, AG-001 assigns corrections.
10. AG-003 re-evaluates when required.
11. AG-002 re-audits.
12. AG-001 reports final result.
