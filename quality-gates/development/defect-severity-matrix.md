# Defect Severity Matrix

| Severity | Definition | Gate impact |
|---|---|---|
| CRITICAL | Security breach, data loss, or unusable deliverable | BLOCKED |
| HIGH | Major functional defect or policy violation | FAIL |
| MEDIUM | Significant issue requiring remediation | FAIL or PASS_WITH_OBSERVATIONS |
| LOW | Minor issue | PASS_WITH_OBSERVATIONS |
| INFO | Observation only | PASS_WITH_OBSERVATIONS |
